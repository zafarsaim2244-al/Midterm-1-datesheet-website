# Integrated GIF Canvas Web App

A clean, responsive web application designed to render Base64-encoded GIF animations side-by-side with an HTML5 `<canvas>` element. Built using vanilla HTML, CSS, and JavaScript.

## Features

- **Embedded Base64 Support:** Renders GIF animations directly from a Base64 string.
- **Canvas Preview:** Automatically scales and centers the GIF image onto an HTML5 Canvas element.
- **Responsive & Dark Themed:** GitHub-inspired dark interface optimized for desktop and mobile displays.
- **Toggle Control:** Simple UI control to toggle image display visibility.
- **Error Handling:** Built-in validation for image loading and base64 string formatting.
